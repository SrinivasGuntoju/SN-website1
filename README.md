# SN Alankarana – Herbal Hair & Skin Care
### *Glow Naturally*

A luxury, production-grade Ayurvedic e-commerce experience inspired by Forest Essentials and Kama Ayurveda. Handcrafted in small artisan batches in India, honoring traditional cold-process saponification with goat milk, French red wine, wild ubtan, activated bamboo charcoal, and fresh papaya enzymes.

---

## 🌿 Brand Assets & Artistry

- **Logo**: Intertwined calligraphic "SN" monogram with a blooming watercolor botanical blossom, regal serif `ALANKARANA` wordmark, and `"Glow Naturally"` script accent.
- **Product Posters & Photography**: 5 slow-cured 100g artisanal bathing bars:
  1. **Goat Milk & Red Wine Soap** – Deep lipid moisturization, red wine antioxidants, petal-soft finish.
  2. **Charcoal & Multani Mitti Soap** – Activated bamboo charcoal pore adsorption + mineral clay sebum regulation.
  3. **Red Wine Soap** – Pure grape polyphenols & resveratrol for youthful radiance and free-radical defense.
  4. **Ubtan Honey Soap** – Vedic bridal Shringar with wild Kasturi turmeric, raw forest honey, and saffron.
  5. **Papaya with Licorice Soap** – Fresh papain enzymes & mulethi root for dark spot and hyperpigmentation correction.
- **Purity Oath**: 100% Handmade • No Parabens • No Sulfates (Zero SLS/SLES) • No Synthetic Colors • Cruelty Free • Retains 100% Naturally Generated Glycerin.

## 🚀 Key Features

1. **Monogram Preloader**: Draws the calligraphic SN monogram, blooms the pink blossom petal, and smoothly reveals the storefront.
2. **Product Compare Matrix (Side-by-Side Modal)**: Select up to 3 handcrafted soaps to analyze their active hero botanicals, clinical & Ayurvedic benefits, bathing rituals, full INCI declarations, and pricing in a clean side-by-side overlay modal with quick "+ Add to Compare" slots and direct basket additions.
3. **Documented Before & After Visible Transformations**:
   - **Face Radiance Transformation**: 21-day documented journey from dullness and post-bath tightness to dewy Ayurvedic Tejas (radiance) and velvety softness using Goat Milk & Red Wine Soap.
   - **Hands & Forearms Sun Tan Removal**: 18-day documented reversal of harsh watch line sun tan and hyperpigmented knuckles using Ubtan Honey Soap and Papaya with Licorice Soap.
   - **T-Zone & Pore Clarity**: 14-day oil-balancing and pore detoxification using Charcoal & Multani Mitti Soap.
4. **Interactive 3-Soap Box Builder**: Live 3-slot visualizer to mix-and-match any 3 soaps with a 15% bundle discount (₹949 vs ₹1,100), personalized calligraphy gift note, and keepsake sleeve selection.
3. **Ingredient Transformation Scroll**: Step-by-step interactive cold-process alchemy from raw harvest to 28-day teakwood cure.
4. **30-Second Ayurvedic Diagnostic Quiz**: 3 questions diagnosing skin feel, concern, and scent profile to prescribe the exact matching herbal bar.
5. **Contiguous PDP & Pincode Checker**: Image zoom, INCI botanical declaration, bathing rituals, customer review submission, and live Indian PIN code delivery checker (e.g. 500001).
6. **Cart Drawer & Free Shipping Progress**: Tracks distance to the ₹599 free shipping threshold, coupon code application (`GLOW10`, `ALANKARANA`), and itemized steppers.
7. **Express Checkout**: Pan-India address validation, UPI / QR instant payments, Razorpay / Cards, and Cash on Delivery (COD).
8. **Order Success & Tracking**: Confetti celebration, Shiprocket air dispatch timeline, and printable tax invoice with brand monogram.
9. **Merchant Admin Portal**: Live sales KPIs, order status fulfillment manager, inventory toggle, price adjustments, and coupon code generator.

## 🛠️ Tech Stack & Deployment

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + custom CSS variables
- **Icons**: Lucide React
- **Animations**: Motion (Framer Motion) + Canvas Confetti
- **State**: React Context with LocalStorage persistence

### Run Locally:
```bash
npm install
npm run dev
```

### Build for Production:
```bash
npm run build
```

Deployable with zero configuration to **Vercel**, **Netlify**, or **Cloud Run**.
